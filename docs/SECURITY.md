# 产品安全边界

中央安全门禁及发布授权由 Action Worker 定义。本文件只规定插件运行时边界。

宿主是文件写入、进程执行、会话访问、工作区修改、模型调用、MCP 配置、凭据与授权的最终权威。插件的 UI 状态、策略结果及声明式能力不得授予额外权限。外部服务调用仅走已授权的公开接口；不得读取或缓存原始凭据，不得自动扩大授权、注入私有接口或降级至本地不受控执行。

Suite 不修改宿主源码、原生语言、遥测模块或隐私设置；仅在公开能力允许时提供插件自身保护，不能宣称关闭所有原生遥测。Code 的 Git、文件、命令与协作调用必须遵循宿主权限及仓库绑定。Shared 不得拥有业务授权决策。

能力缺失、授权失败、身份不一致或服务撤销时拒绝相应操作并保持原生行为。卸载清理插件注册、监听、定时器与临时状态。现有权限、凭据、路径、并发及生命周期回归测试必须保留。

发现漏洞应避免公开密钥或完整敏感日志；按仓库安全渠道报告。修复必须经过既有中央门禁，不能用降低验证或开放权限代替。

Code GitHub 传输层在解析凭据前复核仓库身份、账号所属 owner 及实际请求路径；仅允许该仓库 API 与受限的同 owner 资料、该仓库 Skill 只读检索。原有 native 身份核验和 GitHub 权限仍为必要条件；不新增仓库名单限制。公开 Skill 检索与签名日志下载保持无凭据通道。该约束不代表对宿主全部网络传输实施控制。
